⚙️ Configuración y Permisos de Roles

Define las políticas de red por defecto para cada nivel. Al aprobar una estación de trabajo, heredará automáticamente estos valores o podrás personalizarla de forma individual.

NIVEL 1 Estándar / Operativo

Alumnos / Trabajadores / Clientes

Aplica para los puestos estándar del entorno. Diseñado para un uso controlado y seguro con filtrado y límite de sesión.

Ej: 120 min. Ingresa 0 para navegación ilimitada.
Si está desactivado, aplican las reglas de bloqueo web configuradas.
Muestra el botón en el portal para solicitar reactivación al expirar el tiempo.
NIVEL 2 Supervisión / Avanzado

Docentes / Jefes de Área / Encargados

Aplica para profesores, facilitadores o encargados. Diseñado para conexión fluida y continua sin cortes imprevistos.

0 = Sesión continua sin límite de tiempo.
Navega libre de restricciones web salvo que se aplique una regla explícita.
Habilitado por defecto para estaciones Nivel 2.
